# QCD-Project
Numerical pipeline to compute gluon and parton production in heavy ion collisions based on:

[arXiv:2502.09721](https://arxiv.org/pdf/2502.09721), [arXiv:2409.06788](https://arxiv.org/pdf/2409.06788),
[arXiv:2308.11713](https://arxiv.org/pdf/2308.11713).
